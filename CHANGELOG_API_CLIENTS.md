# Changelog для API-клиентов (игровые серверы)

## 1. Серверные привилегии — мультисерверность

### Новое поле `server_name` в запросах привилегий

**GET `/api/v1/game/privileges/players`**
- Добавлен опциональный параметр `?server_name=ASPER1` (или `ASPER2`)
- Если указан — возвращает только привилегии для этого сервера (и глобальные, где `server_scope=null`)
- Новое поле в ответе: `"server_scope"` — `null` (все серверы), `"ASPER1"` или `"ASPER2"`
- Новое поле в ответе: `"player_name"` — никнейм игрока из БД

**GET `/api/v1/game/privileges/player?steamid=...`**
- Добавлен опциональный параметр `?server_name=ASPER1`
- Если указан — возвращает привилегии только для этого сервера
- Новое поле в ответе: `"server_scope"` — область действия привилегии
- Новое поле в ответе: `"player_name"` — никнейм игрока

**Рекомендация**: передавайте `?server_name=ASPER1` (или ASPER2) при каждом запросе привилегий, чтобы получать только релевантные привилегии.

## 2. Диспетчерская — Discord уведомления

Теперь каждое сообщение из диспетчерской игрового сервера автоматически отправляется в назначенный Discord-канал.

**Настройка (через Discord бота):**
- `!setdispatch1 #канал` — канал для сообщений ASPER1
- `!setdispatch2 #канал` — канал для сообщений ASPER2

Важно: сообщения отправляются только если в теле запроса есть поле `server_name` (ASPER1 или ASPER2). Без него уведомление не будет отправлено.

---

## 3. Уведомления о наказаниях

Теперь уведомления отправляются о ВСЕХ типах наказаний (предупреждение, выговор, кик, бан).

**Настройка:**
- `!setpunishments #канал` — канал для всех наказаний
- `!setbans #канал` — дополнительный канал только для банов

## 4. Публичный API кораблей

**GET `/api/v1/public/submarines`** — список всех кораблей (без авторизации)

Ответ:
```json
{
  "submarines": [
    {
      "id": 1,
      "name": "Акула",
      "project_type": "Корабль",
      "author": "Велес",
      "crew": {"raw": "5-7-10", "min": 5, "avg": 7, "max": 10},
      "crew_min": 5,
      "crew_avg": 7,
      "crew_max": 10,
      "weapons": "...",
      "deployed_server_1": true,
      "deployed_server_2": false,
      "latest_version": 3,
      "latest_filename": "акула_v3.sub"
    }
  ],
  "total": 1
}
```

**GET `/api/v1/public/submarines/{id}`** — данные одного корабля со списком версий.

## 5. Поле crew в формате min-avg-max

Поле `crew` теперь хранится в формате `"min-avg-max"`, например: `"5-7-10"`.

При чтении через API поле `crew` возвращается как объект:
```json
{
  "raw": "5-7-10",
  "min": 5,
  "avg": 7,
  "max": 10
}
```

Дополнительно для удобства: `crew_min`, `crew_avg`, `crew_max` как отдельные поля.

## 6. Диспетчерская — новые лейблы отправителя, статус раунда в Discord

**Диспетчерская:** сообщения игрока теперь подписываются локацией текущего раунда (`📻 {локация}`) вместо имени игрока, либо `❓ Неизвестный сектор`, если раунд не идёт. Сообщения диспетчера подписываются `📡 Региональный диспетчер`. Сообщения, отправленные через веб-панель диспетчерской, теперь тоже дублируются в Discord-канал (раньше уходили только игроку в игру).

**Статус раунда:** добавлен автообновляемый (раз в минуту + мгновенно при начале/окончании раунда) embed с локацией, кораблём, миссией, количеством игроков и таймером до прибытия челнока снабжения. Питается двумя новыми опциональными полями в `POST /api/v1/server/players` — см. `GAME_SERVER_API_GUIDE.md`, раздел «Расширенные поля»: `submarine_health` (0-100) и `supply_shuttle_eta` (секунды до прибытия, считая от момента запроса).

**Настройка (через Discord бота):**
- `!setroundstatus1 #канал` — канал статуса раунда для ASPER1
- `!setroundstatus2 #канал` — канал статуса раунда для ASPER2

### Слэш-команда `/close`

Доступна в тикет-каналах для администраторов и ролей, прописанных в `ping_roles`.

- `/close minutes:15 answer:Принято к рассмотрению` — закрыть через 15 минут
- `/close minutes:0 answer:...` — закрыть через 15 секунд  
- Повторный вызов `/close` отменяет закрытие
- После закрытия создатель тикета получает DM с темой и итоговым ответом
