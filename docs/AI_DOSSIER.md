# AI-досье игрока

NexusData собирает профиль, статистику, наказания, заметки, метки, ловушки,
сессии и ограниченный срез игровых логов за последние 30 дней. Сырые IP и
Discord ID передаются Qwen по согласованному решению, но prompt запрещает
модели повторять их в сводке без необходимости.

Очередь хранится в таблице `ai_player_dossiers`. Для одного игрока существует
одна запись: `queued`, `running`, `succeeded` или `failed`. Воркер обрабатывает
одну запись за раз. После рестарта просроченная lease-запись возвращается в
`queued`; при ошибке старые `result_json`, `summary_text`, `input_hash` и
`generated_at` не затираются.

Настройки endpoint и ключа живут только в окружении NexusData:

```env
AI_DOSSIER_URL=https://213.108.170.48:8000/v1/chat/completions
AI_DOSSIER_API_KEY=...
AI_DOSSIER_TLS_CA_FILE=/etc/ssl/certs/koboldcpp-player-dossier-ca.pem
```

Внутри NexusData доступны ручки профиля и тестовый запуск первых десяти
активных игроков. Общие переключатели находятся в карточке `AI-досье` на
странице администрирования. Prompt лежит в `prompts/player_dossier.md` и через
браузер не редактируется.

Запрос к KoboldCpp дополнительно включает жёсткий компактный JSON-контракт и
`response_format: json_object`; это защищает от обычного markdown-ответа и не
даёт маленькой модели тратить лимит вывода на перечисление всех сессий.

Для диагностики суперпользователь может увидеть ограниченный raw `message.content`
последнего запуска в AI-центре. Он хранится только для записи запуска, ограничен
12000 символами и не выдаётся обычным модераторам, списку запусков или общим API-ответам.
