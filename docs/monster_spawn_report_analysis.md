## Новое поведение

Нет второй системы адаптации. Исправлена существующая: допускаются только завершённые подтверждённые бои с игроками, положительной сложностью и без пересекающегося боя. Обучение волны/норматива/вида ограничено первыми пятью пригодными наблюдениями за раунд; общий и корабельный EMA обновляются один раз за раунд, максимум на 0,01, диапазон 0,8–1,2. Волновые/корабельные наблюдения ограничены 0,8–1,2. Эффект включается после трёх подходящих samples (для общего EMA — трёх раундов). Норматив меняется максимум на 2% за наблюдение, диапазон 0,5–2 исходной нормы. Видовая угроза меняется максимум на 0,01 за независимую одновидовую волну и ограничена ±20% каталога и диапазоном 0,3–2,5.
Старые заражённые автоматические EMA/норматив/видовые оценки инвалидируются assessment_version=1; счётчики истории, изученные шаблоны, мобильность, ручные wave/species overrides сохраняются. Отчёты и БД не переписываются. Первый ненулевой снимок экипажа помечается временем; отсутствие такого снимка остаётся неизвестным для API. Новое summary считает все наблюдаемые волны, уникальные подтверждённые смерти и только пригодные performance_samples. Затопление остаётся суммой волновых экспозиций и явно маркируется API.
API передаёт LLM численность, ожидаемое время и состояние монстров, а также признаки качества всей выборки. Legacy performance не используется для новой оценки силы; при отсутствии пригодных данных assessment.performance=null. sample_support — доля от пяти наблюдений, не статистическая уверенность. Оценка остаётся характеристикой встречи, а не выделенной причинной силой экипажа.
