# NexusData

Панель администрирования, модерации и аналитики для игровых серверов
Barotrauma (ASPER), плюс API для интеграции с игровыми серверами, Discord и
внешними сервисами.

Единое приложение: FastAPI-бэкенд отдаёт REST API и раздаёт React-SPA
(админ-панель), встроенный Discord-бот работает в том же процессе, а всегда
живой прокси спереди обеспечивает деплой без простоя.

---

## Возможности

- **Игроки** — профили, время в игре, статистика, привязка к Discord/ND-аккаунту.
- **Модерация** — предупреждения, выговоры, кики, баны; синхронизация с игровым сервером через систему действий (`ServerAction`).
- **Права и отделы** — гибкая система привилегий: индивидуальные, групповые и производные от отделов (суммируются), раздельно по серверам (ASPER1/ASPER2).
- **Рейтинги** — по игровым ролям и по отделам, с автопубликацией эмбедов в Discord.
- **Диспетчерская** — радиосообщения, отправка/возврат челнока снабжения, груз, торпеды; внешнее API и вебхуки.
- **Документы** — библиотека с редактированием через ONLYOFFICE, публикация в Discord.
- **Тикеты** — система обращений через Discord (кнопки/слэш-команды) с зеркалированием в панель.
- **Обзор мира** — живое состояние раундов (локация, корабль, миссия, экипаж, ETA челнока).
- **Аналитика** — онлайн-таймлайн, пиковые часы, длительность сессий, ретеншн, топ игроков.
- **Античит и аномалии** — фоновое обнаружение твинков и статистических выбросов.
- **Sub-projects / Полигон** — публикация кораблей, управление тест-серверами через Pterodactyl.
- **Кэш на стороне игрового сервера** — сверка хэшей, чтобы не тянуть большие JSON без изменений (отказоустойчивость при потере связи с API).

## Стек

- **Backend:** Python, FastAPI, SQLAlchemy, MySQL (`pymysql`)
- **Frontend:** React 19 + TypeScript, Vite (собирается в `frontend/dist`, раздаётся бэкендом)
- **Discord-бот:** discord.py — встроен в процесс бэкенда
- **Прокси/деплой:** Starlette + uvicorn (`proxy_server.py`), режим техработ
- **Опционально:** ONLYOFFICE Document Server, SFTP (логи), Pterodactyl API

## Архитектура

```
                          (HTTPS 443)
    Браузер / игровой сервер ─► nginx ─► proxy_server.py ─► api_server.py
                                 (:443)   (публичный :8000)  (внутренний :8001)
                                                                   │
                                                     ┌─────────────┼──────────────┐
                                              FastAPI (SPA+API)  фоновые       Discord-бот
                                                                 воркеры       (discord.py)
                                                                   │
                                                                 MySQL
```

- `proxy_server.py` — всегда держит публичный порт; показывает страницу техработ, когда бэкенд остановлен/обновляется, и сам перезапускает его при падении.
- `api_server.py` — реальный бэкенд на внутреннем порту, запускается прокси.
- Discord-бот и фоновый планировщик работают внутри процесса бэкенда.

## Быстрый старт (локально)

Требуется Python 3.12, Node.js 20+, MySQL 8+. Зафиксированные версии
зависимостей пока не совместимы с Python 3.13.

```bash
# 1. Бэкенд
python -m venv venv
source venv/bin/activate            # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 2. Фронтенд
cd frontend && npm ci && npm run build && cd ..

# 3. Конфигурация
cp .env.example .env                # заполнить значения (см. ниже)

# 4. Запуск (прокси поднимает бэкенд сам)
python proxy_server.py
# → http://127.0.0.1:8000
```

Схема БД и миграции создаются автоматически при первом старте (`init_db()` в
`database.py`) — отдельного шага миграции нет.

## Конфигурация

Все настройки — через `.env` (см. [`.env.example`](.env.example) с описанием
всех полей). Обязательный минимум: `DATABASE_URL`, `SECRET_KEY`, `API_KEY`,
`CORS_ORIGINS`, Discord OAuth (`DISCORD_CLIENT_ID/SECRET/REDIRECT_URI`) и бот
(`DISCORD_BOT_TOKEN`, `GUILD_ID`). В продакшене `DEBUG=false`.

Сгенерировать секреты:
```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

## Структура проекта

```
proxy_server.py          всегда живой прокси (точка запуска)
api_server.py            запуск бэкенда (uvicorn)
main.py                  сборка FastAPI-приложения, роутеры, middleware
config.py                настройки (.env)
database.py              engine/сессии + init_db() и миграции
models.py                ORM-модели
schemas.py               Pydantic-схемы
security.py              аутентификация, права, rate limiting
workers.py               фоновые периодические задачи
task_scheduler.py        приоритетный планировщик задач
services*.py             бизнес-логика (аналитика, аномалии, логи, реплеи, …)
routes/                  HTTP-эндпоинты
discord_bot/             встроенный Discord-бот
frontend/                React-SPA (собирается в frontend/dist)
static/                  статические ассеты (иконки предметов и т.п.)
deploy/                  инструкции по развёртыванию и автодеплою
```

## Аутентификация

- **Админ-панель** — вход через Discord OAuth, серверные сессии (cookie `admin_token`).
- **Игровой сервер** — ключ `API_KEY` в заголовке `X-API-Key`.
- **Внешние read-only интеграции** — отдельный `CLIENT_API_KEY`.
